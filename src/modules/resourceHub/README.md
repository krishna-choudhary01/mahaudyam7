# ResourceHub Module

## Overview
`ResourceHub` provides offline-accessible guides, government scheme summaries (e.g., PMEGP, MUDRA, CMEGP), and essential contact points for rural entrepreneurs in Maharashtra.

## Responsibilities
- Offline document cache for scheme eligibility, checklists, and application steps.
- District Industries Centre (DIC) and local bank coordinator directories.

## Phase 1 Status
Architecture defined. Detailed features and business logic will be implemented in subsequent phases per the roadmap.
